# "星笔记" App 使用手册

产品版本：v3.2。文档编号：PROD-NOTE-3.2。

## 产品定位

星笔记是一款团队协作笔记应用，支持多人实时编辑、知识库管理和任务看板。

## 快速开始

1. 注册账号：使用手机号注册，验证码有效期 **5 分钟**。
2. 创建首个笔记本：点击左侧栏"+"按钮，选择"新建笔记本"。
3. 邀请成员：在笔记本设置页点击"邀请"，输入对方手机号或邮箱。
4. 免费版最多创建 **3 个笔记本**，每个笔记本最多 **20 名**成员。

## 核心功能

- **实时协作**：多人同时编辑同一篇笔记，右上角显示在线成员头像，最多 **50 人**同时在线。
- **版本历史**：专业版保留 **180 天**版本历史，免费版保留 **7 天**。
- **全文搜索**：支持标题和正文搜索，搜索结果按更新时间排序。
- **评论与@**：在笔记中@成员会发送站内通知，@所有人需管理员权限。

## 快捷键

| 操作 | 快捷键 |
|---|---|
| 新建笔记 | Ctrl + N |
| 保存 | Ctrl + S（自动保存开启时无需） |
| 搜索 | Ctrl + K |
| 插入待办 | Ctrl + Shift + T |

## 套餐与价格

- 免费版：0 元，3 个笔记本，7 天版本历史。
- 专业版：**29 元/月**，无限笔记本，180 天历史，20 GB 附件空间。
- 团队版：**99 元/月**，含专业版全部功能 + 管理后台 + SSO 单点登录。
