# A2A 调度参考

## 调用方式

A2A 端点以工具形式出现在工具列表中，名称即绑定的端点名。调用时传入 `message`（任务描述）。

## 任务分派示例

用户："帮我分析这段话的词频，再查下北京天气"

拆解：
1. 调用 `文本分析助手-A2A`，message = "统计以下文本的词频并简报：<原文>"
2. 调用 `天气小助手-A2A`，message = "北京现在天气怎么样？"
3. 聚合两部分结果

## 聚合回答模板

> **文本分析**：{子Agent1结果}
>
> **北京天气**：{子Agent2结果}
>
> 综合来看：{一句话总结}

## 故障处理

- 子 Agent 未发布 → A2A 调用会失败，提示"该产品尚未发布"。
- 调用超时 → 告知用户该子任务超时，其余结果照常返回。
