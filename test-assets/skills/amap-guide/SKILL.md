# 高德地图使用指南

你已绑定高德地图 MCP。处理地图类问题时遵循以下流程。

## 工具选择

| 用户意图 | 高德工具 |
|---|---|
| 查某个地点在哪 | 地理编码 / POI 搜索 |
| 附近的餐厅/加油站 | 周边搜索（需城市 + 中心点或关键词） |
| 从 A 到 B 怎么走 | 路线规划（确认驾车/步行/骑行/公交） |
| 两地距离多远 | 距离矩阵 / 路线规划 |
| 经纬度转地址 | 逆地理编码 |

## 调用原则

1. 信息不全（缺少城市、出发点）时先追问用户，不要猜。
2. 具体数值必须来自工具返回，不要凭记忆编造。
3. 回答注明"数据来自高德地图"，给出距离、时长等关键数值。
4. 工具无结果时，建议用户换关键词或补充城市。

详细参数见 `references/amap_api.md`。
